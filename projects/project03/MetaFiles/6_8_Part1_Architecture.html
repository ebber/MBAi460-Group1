Notes for DP-6 review
• RDS = Path A — existing backbone photoapp-db (public); the authsvc DB was created in CP-1. No new RDS, no VPC-attached Lambda.
• Config is file-based — the Lambda reads a packaged authsvc-config.ini; the deploy templates rds_address into it (not env-vars).
• Layers = the committed zips (plain aws_lambda_layer_version; no Docker build).
• Client config = trimsuffix(invoke_url,"/") → autograder hits {invoke_url}/auth.

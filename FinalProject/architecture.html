NoteFlow — Architecture

Serverless, event-driven · async fire-and-forget · MBAI 460 Final Project · excludes the IAM layer

Flow

  1. 1 Authenticate via Google SSO (OIDC); client gets a token.
  2. 2 Client calls API Gateway POST /uploads (JWT-authorized).
  3. 3 API Gateway invokes create-upload.
  4. 4 create-upload writes a PENDING job to DynamoDB and returns a presigned S3 URL.
  5. 5 Client uploads image + media directly to S3 via the presigned URL.
  6. 6 S3 ObjectCreated event enqueues the job on SQS.
  7. 7 SQS triggers the processor Lambda.
  8. 8 processor calls Rekognition (DetectText / DetectLabels).
  9. 9 processor reads the raw object from S3.
  10. 10 processor calls the external Obsidian Vault API → gets the vault page link.
  11. 11 processor writes DONE (+ link) to DynamoDB. Partial extraction → DONE_WITH_GAPS.
  12. 12 Client polls GET /jobs/{id} → status Lambda → DynamoDB → returns the link.
  13. 13 Repeated failures route the message to the DLQ.
